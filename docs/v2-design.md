# 第二版实现约定

用户已选择同时保留“清爽学习、纸感手册、深色专注”三种设计，并授权完成后发布第一版到 main、第二版到独立分支。

## 第二版

- Python + pywebview / Windows WebView2 呈现本地 HTML，沿用 SQLite、Youdao 抓取、抽测及 Excel 模块。
- 三种主题有独立配色、字体及导航布局；切换主题不重新启动界面，不丢查词输入和抽测进度，选择保存在本机。
- 词库支持卡片和表格、中文及英文搜索、新词/到期/薄弱/已掌握筛选、加入时间、字母、掌握度、复习日期、正确率排序。正确率排序将未测试的词放在末尾，减少把未知当成错误的混淆。
- 词条详情展示完整释义、来源、备注、复习历史；可编辑、删除并保留历史。表格标题可点选排序。
- 无外部脚本、字体、图片或账号依赖。查词由 Python 主动联网；界面文件在本机打包，离线可管理及抽测。
- 保留 Tkinter 第一版源码和可执行文件。第二版使用相同数据库结构，不重新导入，不改变掌握度或抽测规则。

## 验收

回归现有测试，增加筛选/排序边界、主题与设置持久化、本地桥接跨线程调用、三主题界面交互测试，检查不同窗口宽度，完成真实 WebView2 及打包程序启动验收。

## 发布

main 保存当前有道版作为第一版稳定基线。v2-themes 从该基线创建，提交第二版源码、测试、说明与构建脚本。只发布程序代码；个人数据库、工作簿、备份与日志留在本机。
