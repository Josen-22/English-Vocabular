# 进阶版 2.1：五项学习功能

沿用第二版的三种主题、卡片与表格、排序筛选及原有本地数据。打开 `本地单词本_进阶版.exe`。

## 1. 选出这次要记的意思

在查词或编辑词条时，“这次要记的意思”提供义项勾选，也可以直接编辑“抽测使用的中文提示”。例如 firm 的完整释义可以保留公司、坚固、坚定等含义，抽测只提示“n. 公司”。

留空时使用完整释义；“使用完整释义”按钮可清空当前选择。点击保存后生效。已生成题组中的提示保留快照，之后修改词条不会换掉正在做的题。

## 2. 错词和薄弱词再练

完成每日题组后，点“再练本轮错词”，抽取本轮“模糊 / 不认识”的词。也可随时点“练薄弱词”，练习已经测试且掌握度 0—1 的词。

专项练习独立保存，每次评级会增加真实复习记录并更新掌握度，但不会改写原来的每日结果。未完成时可以退出软件，之后点“继续上次专项”恢复；跨天也可以继续。点“返回每日抽测”可以回到每日题组。

专项数量最多采用当前每日数量，题型按当前设置分配。没有符合条件的词时会说明，不会生成空练习。

## 3. 音标和英美发音

新的有道查询会一起填入英美音标。旧词未带音标时，可点“重新查询有道”，预览后使用并保存。查词编辑、词条详情和抽测卡片都有“英式发音 / 美式发音”。

发音仅在点击按钮时读取和播放，不随页面或单词自动播放。拼写题在翻开答案后才显示发音，避免泄露答案。

在“学习设置”中可开启发音缓存。开启后，点击过的发音保存到本机“数据/发音缓存/”，之后断网可重播。没有缓存的词仍需要联网。缓存开关影响之后的下载；已有有效缓存仍可使用。音频缓存可以重新下载，不随 SQLite 备份打包。

## 4. 调整每天的学习强度

右上角“学习设置”支持每日 1—50 词、新词比例 0—100%、词义回忆比例 0—100%。旧词比例和拼写比例由剩余部分组成。默认仍是每日 10 词、新词和旧词各半、词义和拼写各半。

新设置只影响之后新建的题组，已经生成的每日题目保持固定。数量不足时按实际词库补足，同组不重复出词。设置窗口会显示预计分配数量。

## 5. 查看最近七天的周报

导航中的“学习周报”展示今天及之前六个本机自然日：学习天数、去重复习词数、作答次数、完成的每日题组、每日活动、词义与拼写分别的正确率、最常出现的待巩固词。

专项复测也算真实作答次数，但不会增加每日题组完成次数。“认识”计为正确，“模糊 / 不认识”列入待巩固。旧记录中未标明词义或拼写的部分单列说明，不纳入两种题型的正确率。没有作答的题型显示“暂无记录”。

## 数据与兼容

升级前已备份。新增义项、音标、专项题组使用附加数据表，不改变旧版核心词库结构。完整 SQLite 备份包括义项、音标和专项进度；Excel 导出附加学习义项及音标列，仍保留完整词典释义。原格式 Excel 仍可导入。

主题、学习强度和缓存开关保存在本机的“界面设置.json”，不包含在词库数据库备份中。只有主动查词、读取未缓存发音时联网，不接入 AI，不需要付费 API 密钥。
