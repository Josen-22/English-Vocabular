# 第二版使用说明

打开 `本地单词本_第二版.exe`，无需启动 Codex。Windows 需要已安装 Microsoft Edge WebView2 Runtime；当前电脑已验证可用。

## 三种界面

右上角“界面风格”可随时切换并自动记住选择：

- 清爽学习：浅色与绿色，侧栏导航，适合日常查词、整理和抽测。
- 纸感手册：暖纸色、衬线字体和横向导航，抽测页带今日篇目。
- 深色专注：深色与淡紫色，横向导航、聚焦词卡，大窗口可随手进入查词。

切换主题不会关闭页面，不会清空正在编辑的词条或重置当天题组。三种主题使用同一个单词本。

## 单词手册

卡片视图展示单词、词性、释义、掌握度、正确率、抽测次数和复习日期。点卡片查看完整释义、备注及复习历史，可编辑或删除词条。删除保留历史记录。

右侧可切换表格视图，表格标题也可以点击排序。两种视图使用同一套搜索、筛选和排序。

排序方式：最近加入、最早加入、字母 A→Z、字母 Z→A、掌握度低→高、掌握度高→低、优先复习日期、正确率低→高、最久未复习。相同日期按词条编号稳定排序。正确率排序将未测试的词放在末尾，未测试不算错误。

筛选：全部、未测新词、已到复习日、薄弱词、学习中、已掌握。薄弱词为已测试且掌握度 0—1，学习中为已测试且掌握度 2—3，已掌握为掌握度 4—5。到期筛选针对已测试且到达复习日期的旧词。顶部掌握情况数字可以点击筛选。

搜索覆盖英文、中文、词性、来源和备注。排序、筛选及视图会记住；搜索文字只在当前窗口内保留。

## 查词、抽测和数据

查词和第一版相同：有道自动填好词性与释义，点“收入单词手册”才保存。已有词保留原内容；重新查询时先展示新释义，由你决定是否使用。备注和学习进度保留。

每日题组、新旧词配比、混合题型及掌握度规则延续第一版。拼写核对后仍可手动修正判定，答题立即保存；退出后可继续。跨天时切换到当天题组。

页面底部“数据与备份”可以导入原格式 Excel、导出、完整备份和恢复。恢复前会确认，并自动保存当前数据。每天首次启动第二版也会做一份备份。

默认数据目录仍是 `D:\CC聊天记录\雅思学习\本地单词本\数据\`。数据库格式兼容第一版，两版都可以读取；建议同时只开一个版本。界面偏好另外保存在 `界面设置.json`，不改变词条及学习进度。

## 从源码运行

```powershell
python -m pip install -r src/requirements.txt
python src/desktop.py
```

指定其他数据位置：`python src/desktop.py --home 'E:\Vocabulary'`。

打包：执行 `src/build.ps1`。第一版入口 `src/main.py` 仍保留供兼容使用。

界面样式、脚本和字体均在本机；除主动有道查词外，软件可以离线使用，不需要 AI、API 密钥或账号。
