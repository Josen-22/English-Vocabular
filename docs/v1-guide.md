# 本地单词本

双击本目录中的 **打开单词本.cmd**，或打开 `程序/本地单词本_有道版.exe`。
无需打开 Codex，无需安装 Python，无需账号。除网页查词外，日常使用不需要网络。

## 查词与收录

1. 打开“查词收录”，输入单词或短语。
2. 点击“有道查词”或按回车，软件会联网读取有道词典，自动填好词性、中文释义和来源。
3. 浏览后点击“收入单词本”即可，不需要复制粘贴或手工整理。需要时仍可编辑释义、填写自己的备注。

输入已有单词时会打开本地词条，保留你原来的释义和学习进度。点击“重新查询有道”会预览新释义，选择“使用这些释义”后，再点“保存修改”才会写入；原来的备注和学习记录保留。

多词性的释义按行分组，保持词性和含义的对应关系。只收录有道基础英汉释义，不自动收录广告、网络释义和例句。长释义可滚动查看，收录按钮固定在底部。

查询期间可继续使用软件；输入变更或清空后，旧查询不会回填。查词失败时会显示提示并保留当前内容，不会保存空释义；可点击“查看有道原网页”辅助查看。仅在主动查词时联网，不需要 AI、API 密钥或账号。公开网页可能改变结构或暂时限制访问，此时可稍后重试。

## 今日抽测

每天点击“开始今日抽测”，生成固定题组，默认 5 个未测新词和 5 个旧词，词义回忆、英文拼写各半。旧词优先选择到期、掌握度低、较久未复习的词。数量不足时由另一类补足，总词数不足 10 个则全部抽测。

- 词义题：先回忆中文，点击“翻开释义”，再选“认识 / 模糊 / 不认识”。
- 拼写题：输入英文，点击“检查拼写”；忘记时也可留空检查。软件提供建议，最后由你点击掌握情况确认，允许修正其他可接受拼写。
- 选择掌握情况后立即保存并进入下一题。关闭重开后可继续；当天完成后显示结果，次日可开始新的题组。
- 如在午夜跨天使用，会切换到新一天；旧题组和已完成答案保留历史。

掌握度为 0—5 级：认识升一级，模糊降一级，不认识归零。对应下次复习间隔为 1、1、3、7、14、30 天。正确率只把“认识”计为正确。

## 我的单词本

支持按英文、中文释义、来源或备注搜索。双击词条编辑；“查看详情与历史”可查看完整释义、正确率和历次回答。

删除词条需要确认。删除后不再进入未来的新题组，历史记录以及当天已经生成的题目保留。再次输入相同单词、保存已有词条，可将它恢复。

## 数据与备份

右下角“数据与备份”提供：

- **导入 Excel**：支持原《雅思迭代单词本.xlsx》格式，两个工作表为“词库”“复习记录”，表头在第 5 行。重复导入不会增加重复记录，已有词条的后续编辑和掌握度不会被覆盖。发生格式错误则整次导入取消。
- **导出 Excel**：包含词条、掌握度、统计和复习记录，也包含删除标记。完整的每日题组进度请使用数据库备份。
- **完整备份**：保存词条、历史记录、每日题组与进度到一个 `.sqlite3` 文件。
- **从备份恢复**：替换当前数据前会先自动备份当前状态。恢复前的文件保存在“备份”目录，必要时可再次恢复。

每天首次启动、导入前和恢复前会自动备份。原 Excel 作为存档保留，软件不会自动写回它。

## 文件位置与源码

固定根目录：`D:\CC聊天记录\雅思学习\本地单词本\`

- `程序/本地单词本_有道版.exe`：新版可双击启动的程序，启动入口已指向此版本。
- `数据/单词本.sqlite3`：当前使用的数据库。
- `备份/`：完整备份，请定期复制到其他存储位置。
- `源码/`：Python 源码、依赖清单、自动测试和 `build.ps1` 打包脚本。
- `验证/`：数据迁移核对与测试结果。

程序复制到其他位置后，默认仍使用上述数据目录。需要另设根目录时，可运行：

```powershell
& '.\程序\本地单词本_有道版.exe' --home 'E:\我的单词本'
```

从源码运行：安装 `源码/requirements.txt` 的依赖后，运行 `python 源码/main.py`。重新打包可在 PowerShell 执行 `源码/build.ps1`。

第一版面向一人一台电脑；建议同时只开一个窗口。不提供云同步、发音、批量抓取或后台提醒。
