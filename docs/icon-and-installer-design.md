# C 款图标与安装包

用户已在四款概念中选择 C「每日词卡」。正式图保留绿色底、米白叠放词卡、字母 a 和橙色勾选；去掉说明文字与展示背景，方形图以透明边缘供 Windows 使用。

应用资源提供 256 像素 PNG 和包含 16、20、24、32、40、48、64、128、256 像素的 ICO。程序文件、窗口、任务栏及界面左上角使用同一图形，三种主题共享身份。

安装包采用 Inno Setup，当前用户安装，无需管理员权限，提供开始菜单和可选桌面快捷方式。程序安装到用户应用目录；已有 D 盘词库路径保持不变，其他没有 D 盘的电脑使用 LocalAppData/EnglishVocabular。卸载仅移除程序，不删除数据与备份。不打包个人数据库、Excel、缓存或学习记录。

提供 64 位安装包、便携 ZIP、SHA256 和简短说明。系统缺少 WebView2 时，安装器调用随包附带的微软引导器安装，需要联网；已有运行环境时可离线安装。GitHub 的 main 保留第一版，源码更新在 v2-themes，安装文件放 Release。

验证包括现有测试、ICO 多尺寸与透明度、隔离安装、安装后程序运行及卸载保留数据。所有验证使用独立目录。
