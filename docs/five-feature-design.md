# 五项学习功能扩展（2.1）

范围已按用户选择锁定为待办前五项：学习义项、错词专项复测、音标与英美发音、自定义强度、最近七天周报。沿用三主题、SQLite、有道公开网页和本机数据。

- 学习义项独立保存，完整词典释义保留；可勾选按分号拆出的义项或自行填写。未选择时抽测使用完整释义。生成题组时保存提示快照，之后编辑不改变已生成题目。
- 专项复测支持当天完成题组的模糊/错误词、全库薄弱词；独立会话、断点续练、每次评级单独记入复习历史并更新掌握度。每日题组结果不回写。专项未完成可跨天继续。
- 查词同时保存英美音标；发音只在点击时读取有道公开音频资源。用户可开启磁盘缓存，已缓存发音断网可播放，不主动播放。
- 每日数量允许 1—50，新词和词义题比例允许 0—100%。默认 10、50%、50%。新设置只影响之后生成的新题组；专项复测使用当前题型比例。
- 周报包含今天及之前六天的学习天数、去重复习词数、答题次数、完成的每日题组、每日活动、词义/拼写分别正确率和高频错词。模糊与不认识均列入待巩固；未记录题型的旧记录单独统计，不冒充词义或拼写。
- 使用附加数据表，不修改既有核心表结构或版本号，以便旧版本继续读取基础词库与学习记录。正式升级前备份，所有开发和验收使用隔离数据库。

验证：现有测试回归；新增事务原子性、旧数据兼容、义项快照、设置边界和固定题组、复测幂等/跨天/独立性、七天统计边界、音频校验/缓存离线测试；三主题交互、真实 WebView2 和打包验收。
