# 后续可做的改进

第二版已覆盖三主题、卡片/表格、搜索、筛选和排序。下一步优先解决实际学习中的两类摩擦：释义太长、错词缺少单独回练。

## 1. 学习义项（优先）

保留完整词典释义，同时允许为抽测选一条“本次要记的意思”。例如 firm 可以专门记“公司”，其他词义仍能在详情查看。这样看中文默写英文时提示更明确，也避免长段释义占据抽测页面。可先做手动勾选义项，继续不依赖 AI。

## 2. 错词专项复测（优先）

每天十题完成后，能一键重练本轮“模糊 / 不认识”的词，或按筛选结果练薄弱词。专项练习与每日固定题组分开记录，让当天结果和后续进步都能保留。

## 3. 音标与英美发音

查词时一起提取音标，按需播放词典发音，可选择缓存到本机。对听力场景帮助较大；先做明确点击播放，避免开程序或切页面自动出声。

## 4. 自定义学习强度

保留每日十词默认值，允许设置每日数量、新旧词配比、词义 / 拼写题型比例。改设置只影响尚未生成的新题组，避免正在做题时换题。

## 5. 本地学习周报

按最近 7 天显示学习天数、完成词数、词义与拼写分别的正确率、最常出错的词。只使用真实复习记录，帮助判断问题在词义还是拼写。

## 6. 批量整理

词库多选、批量标记来源、导出筛选结果，以及粘贴单词列表后逐个排队查词。批量联网查询需要限速、暂停与失败重试，不让一次错误导致整批丢失。

建议先试用第二版几天，记录最常发生的卡点，再从“学习义项”和“错词复测”中选下一项。现有工具仍面向单人本地使用，暂无必要加入账号或云端系统。
